# Task Manager

Простое приложение для управления задачами.

Проект демонстрирует:

- **ООП** — классы `Task` и `TaskManager`.
- **Графический интерфейс** — Tkinter (окна, кнопки, формы ввода, календарь).
- **Работу с файлами** — чтение/запись задач в JSON.
- **Систему контроля версий** — Git/GitHub.

## Установка

1. Установите Python 3.x (https://www.python.org/downloads/).
2. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/ваш-логин/task-manager.git
   cd task-manager
   ```

3. (Рекомендуется) Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux/macOS:
   source .venv/bin/activate

   pip install tkcalendar
   ```

   `tkcalendar` нужен для виджета-календаря при выборе даты. Без неё
   приложение автоматически использует обычное текстовое поле для даты.

## Запуск

```bash
python gui.py
```

1. Заполните поля: название, описание, срок выполнения (дата выбирается календарём).
2. Нажмите **Добавить задачу** — задача появится в списке.
3. Выберите задачу в списке и нажмите **Удалить задачу** — она будет удалена.
4. Задачи автоматически сохраняются в файл `tasks.json` и загружаются
   при следующем запуске программы.

## Функциональность

- Добавление/удаление задач.
- Автосохранение в JSON-файл (`tasks.json`).
- Загрузка задач при запуске.

## Структура проекта

- `classes.py` — классы `Task` и `TaskManager` (логика и файловые операции).
- `gui.py` — графический интерфейс на Tkinter (точка входа).
- `tasks.json` — файл с данными задач.
- `README.md` — описание проекта.
